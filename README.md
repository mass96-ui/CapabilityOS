# CapabilityOS

CapabilityOS is a monorepo foundation for a modern application platform built with pnpm, Next.js, FastAPI, PostgreSQL, Docker, and GitHub Actions.

## Repository Structure

- apps/web: Next.js frontend
- apps/admin: Next.js admin dashboard
- apps/api: FastAPI backend
- packages/ui: shared UI components
- packages/types: shared TypeScript types
- infrastructure: deployment and environment configuration
- docker: container definitions
- docs: documentation
- tools: developer utilities

## Getting Started

1. Install pnpm
2. Install dependencies with `pnpm install`
3. Start development services with `pnpm dev`
